🏛️ PROTOCOLO: GÉNESIS MONETIZACIÓN

Flujo de Trabajo para Proyectos Comerciales de Alto Valor

Cuando la Usuario emite el comando: "Dame un proyecto monetizable profesional", el Sistema ejecuta este Ciclo de Vida de 5 Fases. No improvisamos; ejecutamos.

1. FASE I: EL ORÁCULO (Validación Estratégica)

"No se escribe código hasta que el valor sea más claro que el código mismo."
Agentes: MARKET_HUNTER | PRICING_GOD | PSYCHO_ANALYST

  • Producto: STRATEGIC_OPTIONS.md
  • Acción: Analizamos tus activos únicos (El Foso), identificamos un hueco en el mercado y definimos el Modelo de Precios (SaaS, Pago Único, Freemium). Respondemos: ¿Quién paga? ¿Por qué? ¿Cuánto?

2. FASE II: EL PLANO (Arquitectura Atómica)

"Mide dos veces, corta una."
Agentes: ARCH_PLANNER | MCP_LINK

  • Producto: implementation_plan.md (Atómico)
  • Acción: Definición del Stack Tecnológico (El Estándar Universal: React/Three.js/Rust). Dividimos el proyecto en tareas verificables de 2-5 minutos. Nada de desarrollos "Big Bang".

3. FASE III: LA FRAGUA (Ingeniería con Superpoderes)

"Si no está testeado, está roto."
Agentes: Legión DEV_CORE + TEST_PHANTOM

  • Producto: Base de Código Grado Producción
  • Metodología: TDD (Rojo-Verde-Refactor).
    1. Rojo: Escribe un test que falle para la feature.
    2. Verde: Escribe el código justo para pasar el test.
    3. Refactor: Limpia y optimiza.
  • Regla: Tipado Estricto (TYPE_GUARDIAN). Nada de any. Nada de alucinaciones.

4. FASE IV: EL ALMA (Inyección Estética)

"Los productos feos no se venden a precios altos."
Agentes: VOID_WEAVER | POET_BRUMA | CSS_ALCHEMIST

  • Producto: El Factor "Wow"
  • Acción: Inyectamos la Estética 161914.
    • Micro-interacciones (Framer Motion).
    • Diseño de Sonido (SFX UI).
    • Visuales que "Respiran" (Shaders/Partículas).
  • Meta: Diferenciación. El producto debe sentirse como un objeto premium.

5. FASE V: EL LANZAMIENTO (Despliegue del Sistema)

"Publica o muere."
Agentes: DEPLOY_MASTER | SEO_SHADOW | SALES_IMPERATOR

  • Producto: URL en Vivo + Embudo de Ventas
  • Acción:
    • Despliegue en Edge (GitHub Pages/Vercel).
    • Inyección de Schemas SEO (JSON-LD).
    • Conexión de Pasarelas de Pago (Stripe/LemonSqueezy).
    • Generación de Copy de Alta Conversión (COPY_KILLER).

Compromiso: No construimos "Juguetes". Construimos Activos Financieros.
