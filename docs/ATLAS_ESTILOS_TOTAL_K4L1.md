## 🖥️ 4. MOTORES VISUALES INTERACTIVOS & EFECTOS DE RENDERIZADO

### 4.1. Lienzo de Partículas Ambientales Dinámicas (`#ambientCanvas`)
Implementado en la raíz de `k4li-anuu-forge/index.html`:
- **Algoritmo:** Canvas 2D nativo con ajuste de resolución automático al `window.resize`.
- **Densidad:** Escala matemática responsiva: `particlesCount = Math.floor(window.innerWidth / 28)`.
- **Física:**
  - Radio aleatorio: `0.8px` a `2.8px`.
  - Deriva continua bidireccional: `speedX: ±0.2px/frame`, `speedY: ±0.2px/frame`.
  - Rebote toroidal (wrapping continuo en los 4 bordes de la pantalla).
- **Reactividad:** El método `initParticles()` lee directamente la variable CSS `--particle-color` computada en `document.documentElement`, adaptando el color del haz al tema seleccionado al instante.
- **Sombra de Brillo:** `ctx.shadowBlur = 8; ctx.shadowColor = p.color;`.

## 🖼️ 6. INTEGRACIÓN UNIFICADA DE LA VARIABLE `--fullwallpaper`

Para garantizar que toda la suite de herramientas mantenga una armonía cinematográfica sin fisuras, se establece la norma canónica para la variable `--fullwallpaper`.

### 6.1. Definición en el Host Principal
En el documento raíz (`k4li-anuu-forge/index.html`):
```css
:root {
  --fullwallpaper: url('assets/wallpapers/kilonova_sovereign.jpg');
}
```
Cuando el motor de auto-rotación conmuta la imagen activa (cada 12 segundos), se actualiza dinámicamente:
```javascript
document.documentElement.style.setProperty('--fullwallpaper', `url('${wp.url}')`);
```

### 6.2. Propagación Inter-Módulos vía `postMessage`
Los 9 componentes embebidos (`ai_benchmark_calculator`, `contract_generator`, `internal_crm`, `market_arbitrage_engine`, `relics_explorer`, `roi_calculator`, `security_audit_tool`, `sovereign_sanctuary`, `terminal_hud`) implementan un listener estandarizado:

```javascript
window.addEventListener('message', (event) => {
  if (!event.data) return;
  
  // Sincronización del Tema Canónico
  if (event.data.type === 'SET_THEME') {
    document.documentElement.setAttribute('data-theme', event.data.theme);
  }
  
  // Sincronización de Fondo Global
  if (event.data.type === 'SET_WALLPAPER') {
    document.documentElement.style.setProperty('--fullwallpaper', `url('${event.data.url}')`);
  }
});
```

### 6.3. Capa de Contraste Protectora en Sub-Componentes
Cada sub-componente aplica un pseudo-elemento de fondo que consume `--fullwallpaper` sin comprometer la legibilidad del texto técnico:
```css
body::before {
  content: '';
  position: fixed;
  inset: 0;
  background-image: var(--fullwallpaper);
  background-size: cover;
  background-position: center;
  opacity: 0.18;
  filter: blur(1px);
  z-index: -1;
  pointer-events: none;
}
```

## 🛠️ 9. MATRIZ DE APLICACIÓN PRÁCTICA (CÓMO CONSTRUIR NUEVAS VISTAS)

Para que cualquier nuevo componente o reliquia respete de forma 100% canónica este sistema:

1. **Encabezado HTML:**
   ```html
   <!DOCTYPE html>
   <html lang="es" data-theme="anuu">
   <head>
     <meta charset="UTF-8">
     <meta name="viewport" content="width=device-width, initial-scale=1.0">
     <script src="https://www.gstatic.com/antigravity/web/dev/tailwindcss.min.js"></script>
     <link rel="preconnect" href="https://fonts.googleapis.com">
     <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
     <link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;600;700&family=Outfit:wght@300;400;600;700&display=swap" rel="stylesheet">
   ```

2. **Declaración de Variables del Tema:**
   Copiar íntegramente el bloque `:root, [data-theme="anuu"]` hasta `[data-theme="neon"]` (Sección 2).

3. **Capa de Fondo Simbiótica:**
   ```html
   <div class="fixed inset-0 z-0 bg-cover bg-center transition-opacity duration-1000 opacity-20 pointer-events-none" style="background-image: var(--fullwallpaper);"></div>
   ```

4. **Escucha de Mensajes Multidominio:**
   ```javascript
   window.addEventListener('message', (e) => {
     if (e.data?.type === 'SET_THEME') document.documentElement.setAttribute('data-theme', e.data.theme);
     if (e.data?.type === 'SET_WALLPAPER') document.documentElement.style.setProperty('--fullwallpaper', `url('${e.data.url}')`);
   });
   ```
