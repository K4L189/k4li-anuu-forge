Comandos Tácticos CLI — Extracción & Carving de Subtítulos

Haz clic en cualquier comando para copiarlo de inmediato
🎙️ Extracción Automática Copiar 📋

Escanea vídeos y pistas de subtítulos en Fotos_recuperadas.

python3 anuu_whisper_extractor.py -i /home/kali/Fotos_recuperadas
💾 Carver Completo con Vídeos Copiar 📋

Tallado exFAT en vivo con extracción nativa y transcripción Whisper.

sudo python3 anuu_photo_carver.py /dev/sdX "Fotos" ... --carve-videos --whisper-subs
⚡ Instalar faster-whisper Copiar 📋

Acelera 4x la transcripción neuronal con CTranslate2 en CPU/GPU.

pip install faster-whisper
🧠 Modelo Medium / Calidad Alta Copiar 📋

Máxima fidelidad fonética para audios complejos o susurros.

python3 anuu_whisper_extractor.py -i ... -m medium --device auto
🎞️ Solo Pistas Incrustadas (Fast) Copiar 📋

Extrae pistas SRT/ASS de MKV/MP4 sin ejecutar transcripción.

python3 anuu_whisper_extractor.py -i ... --extract-embedded-only
🔧 Comando Manual FFmpeg Copiar 📋

Mapeo directo de primera pista de subtítulos a .srt.

ffmpeg -y -i input.mp4 -map 0:s:0 subtitulo.srt
